# 🧪 Empório do Alquimista

Vitrine virtual de poções mágicas inspirada em jogos de RPG, desenvolvida exclusivamente com **HTML5** e **CSS3** (sem JavaScript).

## 🎯 Objetivo
Projeto prático criado para introduzir desenvolvimento web a adolescentes, ensinando na prática como estruturar conteúdo e estilizar uma interface moderna e responsiva.

## 📂 Arquivos do Projeto
- `index.html`: Estrutura semântica da loja, cabeçalho, cards dos itens e rodapé.
- `style.css`: Tema escuro (Dark Fantasia), paleta de cores, tags de raridade e alinhamento dos cards.
- `ycarossauro-mago.png`: Logo do cabeçalho e ícone da aba do navegador (*favicon*).

## 🛠️ Conceitos Aplicados
- **HTML5:** Tags semânticas (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) e configuração de `<link rel="icon">`.
- **CSS3:**
  - **Flexbox (`display: flex`):** Organização dos cards lado a lado com `flex-wrap` e alinhamento automático de botões com `flex-direction: column` + `margin-top: auto`.
  - **Box Model:** Controle de espaçamento (`padding`, `margin`), bordas arredondadas (`border-radius`) e sombras.
  - **Classes Múltiplas:** Reutilização de estilos base (`.raridade`) combinados com modificadores de cor (`.comum`, `.raro`, `.epico`, `.lendario`).
  - **Interatividade Visual:** Efeitos de elevação e destaque com `:hover` e `transition`.

## 🚀 Como Executar
1. Baixe ou clone os arquivos na mesma pasta.
2. Abra o arquivo `index.html` em qualquer navegador.
